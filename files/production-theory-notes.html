01 — FOUNDATION

The Production Function

Production Function
A technological/mathematical relationship showing the maximum output obtainable from every possible combination of inputs, given the state of technology.
General form
Q = f(L, K, N, ...)    — typically simplified to two inputs:   Q = f(L, K)  (Labour, Capital)

Short run vs Long run

Table 1.1 — The two production time horizons
Short RunLong Run
Fixed factorsAt least one factor (usually capital) is fixedAll factors are variable
Variable factorsOne or more factors (usually labour)All factors
Governing lawLaw of Variable ProportionsLaw of Returns to Scale
Scale of operationFixed plant sizePlant size itself can change

Common functional forms (know these for CUET PG)

Cobb-Douglas
Q = A·Lα·Kβ
α+β=1 ⇒ constant returns to scale; α+β>1 ⇒ increasing; α+β<1 ⇒ decreasing
Leontief (Fixed proportions)
Q = min(L/a, K/b)
No substitution between inputs — L-shaped isoquants
Linear (Perfect substitutes)
Q = aL + bK
Inputs perfectly substitutable — straight-line isoquants
CES (Constant Elasticity of Substitution)
Q = A[αL−ρ+(1−α)K−ρ]−1/ρ
Generalises Cobb-Douglas & Leontief as special cases
02 — SHORT RUN

Law of Variable Proportions

Statement
As successive units of a variable factor (e.g. labour) are added to a fixed factor (e.g. capital/land), the resulting increments to output (marginal product) will first increase, then decrease, and finally become negative.

This is the modern, generalised name for what classical economists called the "Law of Diminishing Returns" — it explicitly recognises an initial phase of increasing returns before diminishing returns set in.

Assumptions

  • Constant state of technology
  • At least one factor of production is held fixed
  • All units of the variable factor are homogeneous/identical
  • Factor proportions (the ratio of variable to fixed factor) are variable, i.e., can actually be changed
  • Short-run analysis (fixed factor genuinely cannot be altered)

Exam angle
A firm will always operate in Stage II — never Stage I (fixed factor underused, so expanding variable factor is still profitable) nor Stage III (marginal product is negative, so hiring more labour is irrational regardless of how cheap it is). The exact point chosen within Stage II depends on relative factor prices.

Relationship between AP and MP (a favourite MCQ)

  • When MP > AP, AP is rising
  • When MP = AP, AP is at its maximum (MP curve cuts AP curve at AP's peak)
  • When MP < AP, AP is falling
  • MP can be negative even while AP is still positive (Stage III), but AP itself never becomes negative as long as TP > 0

Why do diminishing returns set in? (Causes)

  • Fixed factor becomes a constraint — each additional unit of the variable factor has less of the fixed factor to work with
  • Indivisibility of the fixed factor is exhausted; further additions can't be matched proportionately
  • Imperfect substitutability between factors
04 — LONG RUN TOOLS

Isoquants & Isocost Lines

Isoquant (Equal Product Curve)
The locus of all combinations of two inputs (L, K) that yield the same level of output. The producer's analogue of the consumer's indifference curve.

Properties of Isoquants

Table 4.1 — Compare directly with IC properties (Topic: Consumer Theory)
#PropertyReasoning
1Negatively sloped (downward)More of one input must be offset by less of the other to keep output constant
2Convex to the originDiminishing Marginal Rate of Technical Substitution (MRTS)
3Higher isoquant ⇒ higher outputMore of both/either input produces more output
4Two isoquants never intersectSame logical contradiction as intersecting ICs
5Do not touch either axis (in the general case)Both inputs assumed necessary for positive output

Marginal Rate of Technical Substitution (MRTS)

Definition
MRTSLK = −ΔK/ΔL  (along an isoquant) =  MPL / MPK

The rate at which capital can be reduced per additional unit of labour, keeping output constant. Diminishing MRTS (as L increases, less K needs to be given up for each successive unit of L) is what makes isoquants convex.

The Isocost Line

Equation
w·L + r·K = C   (w = wage rate, r = rental price of capital, C = total outlay)
Slope of isocost line = −w/r

Exactly analogous to the consumer's budget line — shows all combinations of L and K purchasable for a given total cost outlay at given factor prices.

05 — LEAST-COST CHOICE

Producer's Equilibrium (Least-Cost Combination)

Equilibrium condition
MRTSLK = w/r   (slope of isoquant = slope of isocost line)
Equivalently: MPL/w = MPK/r  (marginal product per rupee spent equalised across inputs)

A producer minimises cost for a given output (or maximises output for a given cost) at the point where the isocost line is tangent to the isoquant — analogous to the consumer's tangency of budget line and IC.

Expansion Path

Expansion Path
The locus of least-cost input combinations (tangency points) as total outlay/output expands, factor prices held constant — analogous to the ICC in consumer theory. It shows how the optimal L–K ratio changes as the firm scales up.
06 — LONG RUN

Returns to Scale

Returns to Scale
Describes how output responds when all inputs are increased in the same proportion (a "scale" change), applicable only in the long run when no factor is fixed.
Table 6.1 — Three cases
TypeCondition (inputs ↑ by k times)Output responseCobb-Douglas condition
Increasing Returns to Scale (IRS)Inputs × kOutput increases by more than k timesα + β > 1
Constant Returns to Scale (CRS)Inputs × kOutput increases exactly k timesα + β = 1
Decreasing Returns to Scale (DRS)Inputs × kOutput increases by less than k timesα + β < 1

Why does Increasing Returns to Scale occur?

  • Indivisibility of certain factors (e.g., machinery) — small scale can't use them efficiently
  • Specialisation & division of labour possible only at larger scale
  • Technical/managerial economies at larger scale
  • Dimensional/geometric economies (e.g., container surface-to-volume ratio)

Why does Decreasing Returns to Scale occur?

  • Managerial diseconomies — coordination and control become harder beyond a point
  • Increasing complexity of decision-making
  • Entrepreneurial/organisational capacity is itself a quasi-fixed factor even in the "long run"
Do not confuse
Law of Variable Proportions (short run, one factor fixed, proportions between inputs change) vs. Returns to Scale (long run, all factors variable, proportion between inputs stays the same, only the scale changes). This is one of the most frequently tested distinctions.
07 — COST — SHORT RUN

Cost Concepts: Types & Definitions

Table 7.1 — The core cost family (short run)
ConceptSymbolFormulaBehaviour
Total Fixed CostTFCConstant, independent of outputHorizontal line
Total Variable CostTVCVaries with outputRises with Q, initially at a decreasing then increasing rate
Total CostTCTC = TFC + TVCTC and TVC are vertically parallel (constant gap = TFC)
Average Fixed CostAFCAFC = TFC/QContinuously falls (rectangular hyperbola) — "spreading overheads"
Average Variable CostAVCAVC = TVC/QU-shaped

Key identities
TC = TFC + TVC   |   AC = AFC + AVC   |   MC = dTC/dQ (independent of TFC, since TFC doesn't change with Q)

Why is MC unaffected by fixed cost?

Since TFC is constant, ΔTFC/ΔQ = 0 for any change in output, so MC = ΔTC/ΔQ = ΔTVC/ΔQ always. This is a frequently tested numerical/conceptual point.

08 — SHORT RUN CURVES

Cost Curves & Their Relationships

The MC–AC / MC–AVC relationship (a near-guaranteed MCQ)

  • When MC < AC (or AVC), the average curve is falling
  • When MC = AC (or AVC), the average curve is at its minimum
  • When MC > AC (or AVC), the average curve is rising
  • MC always cuts AC and AVC from below, at their minimum points — never from above

Why are AVC, AC, MC U-shaped in the short run?

Direct consequence of the Law of Variable Proportions: as MPL first rises then falls (given fixed capital), variable cost per unit first falls then rises — the cost curves are simply the "mirror image" of the AP/MP product curves.

09 — LONG RUN COST

Long-Run Cost Curves & Economies of Scale

Long-Run Average Cost (LAC) — the "Envelope Curve"
In the long run, a firm can choose any plant size (any SAC curve). LAC is the envelope of all possible short-run average cost (SAC) curves — for each output level, LAC picks the SAC curve that gives the lowest cost.

Economies & Diseconomies of Scale

These explain why LAC is U-shaped (falls, flattens, then rises):

Table 9.1 — Internal vs External economies/diseconomies
TypeSourceExamples
Internal Economies (LAC falls)Arise within the firm as its own scale growsTechnical (bigger, efficient machinery), managerial (specialised departments), financial (cheaper credit/bulk buying), marketing (bulk transport, advertising spread over more units)
External Economies (LAC falls)Arise from growth of the industry as a whole, benefiting all firmsBetter infrastructure, skilled labour pool, ancillary/supplier industries developing nearby, R&D spillovers
Internal Diseconomies (LAC rises)Arise within an overly large firmManagerial inefficiency, coordination problems, bureaucratic delay, labour-relations difficulties
External Diseconomies (LAC rises)Arise from over-expansion of the industryRising input prices due to industry-wide competition for scarce resources, congestion, pollution costs
Exam angle
The falling part of LAC is explained by economies of scale; the rising part by diseconomies of scale; the flat minimum stretch (if any) represents the Minimum Efficient Scale (MES) — the smallest output at which a firm exhausts all scale economies.

Long-Run Marginal Cost (LMC)

LMC cuts LAC at LAC's minimum point — the same MC–AC rule applies in the long run as in the short run. At the output where LAC is minimum, LMC = LAC = the corresponding SMC = SAC (all four curves intersect at that single point) — this is a classic diagram-based MCQ setup.

Revenue Concepts & Producer Equilibrium (Quick Bridge)

Revenue definitions

Profit-maximising output condition
MR = MC  (with MC cutting MR from below)

This connects production/cost theory directly to market structure/pricing topics (perfect competition, monopoly) — worth a quick review together since CUET PG often links a cost-curve diagram question to a profit-maximisation follow-up.

13 — SELF-TEST

Practice MCQs

Click each question to reveal the answer & explanation. Multi-statement format mirrors CUET PG style.

Q1. The Law of Variable Proportions operates in: Recall
(a) The long run only   (b) The short run only   (c) Both short and long run equally   (d) Neither

Answer: (b) — it requires at least one fixed factor, which by definition exists only in the short run.
Q2. Which of the following statements about Stage I of production is/are correct? Assertion-set
I. Marginal Product is rising throughout Stage I
II. Average Product reaches its maximum at the end of Stage I
III. A rational producer should stop hiring labour within Stage I
IV. The fixed factor is under-utilised relative to the variable factor

(a) I, II & IV only   (b) II & III only   (c) All four   (d) I & III only

Answer: (a) — Statement III is false: it is irrational to stop within Stage I, since MP is still above AP and output can be expanded profitably.
Q3. If a Cobb-Douglas production function has α = 0.4 and β = 0.5, the function exhibits: Numerical
(a) Increasing returns to scale   (b) Constant returns to scale   (c) Decreasing returns to scale   (d) Cannot be determined

Answer: (c) — α + β = 0.9 < 1 ⇒ Decreasing Returns to Scale.
Q4. Marginal Cost is unaffected by changes in Total Fixed Cost because: Conceptual
(a) TFC is always zero   (b) TFC does not change with output, so its rate of change (ΔTFC/ΔQ) is zero   (c) MC is calculated only from AFC   (d) TFC and MC move in opposite directions by definition

Answer: (b) — MC = ΔTC/ΔQ = ΔTVC/ΔQ since ΔTFC/ΔQ = 0 at every output level.
Q5. The Marginal Cost curve intersects the Average Cost curve: Diagram-based
(a) At AC's maximum point, from above   (b) At AC's minimum point, from below   (c) At any random point   (d) Only in the long run

Answer: (b) — this holds for both short-run (MC–AVC/AC) and long-run (LMC–LAC) relationships.
Q6. Long-Run Average Cost (LAC) is described as an "envelope curve" because: Conceptual
(a) It is always U-shaped   (b) It is tangent to every possible short-run average cost (SAC) curve, selecting the least-cost SAC at each output   (c) It equals TFC divided by output   (d) It lies below every SAC curve at every output

Answer: (b) — for outputs other than the very minimum point of LAC, LAC is tangent to (but not at the minimum of) the relevant SAC curve.
Q7. Which of the following would cause Increasing Returns to Scale? Application
(a) Managerial coordination difficulties   (b) Greater scope for specialisation and division of labour at larger scale   (c) Rising input prices industry-wide   (d) Diminishing marginal product of the variable factor

Answer: (b) — (a) and (c) cause diseconomies/decreasing returns; (d) is a short-run concept (Law of Variable Proportions), unrelated to Returns to Scale.
Q8. The producer's least-cost equilibrium requires: Recall
(a) MRTSLK = r/w   (b) MRTSLK = w/r   (c) MPL = MPK always   (d) Isoquant must be concave at that point

Answer: (b) — the isoquant's slope (MRTS) must equal the isocost line's slope (w/r) at tangency; the isoquant must be convex, not concave, for a true minimum-cost point.
Q9. External economies of scale arise from: Application
(a) A single firm's own internal efficiency gains   (b) Growth of the entire industry, benefiting all firms in it   (c) A firm's bulk-purchase discounts   (d) A firm's specialised in-house R&D department

Answer: (b) — (a), (c) and (d) are all internal economies specific to the individual firm.
Q10. In Stage III of the Law of Variable Proportions: Recall
(a) MP is positive but falling   (b) TP is rising at a decreasing rate   (c) MP is negative and TP is falling   (d) AP is rising

Answer: (c) — Stage III begins exactly where MP turns negative, which is also where TP has passed its peak and starts to decline.
